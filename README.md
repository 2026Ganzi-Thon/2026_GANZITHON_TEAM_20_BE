# NightVault · 심야 걱정 금고

NightVault는 간지톤에서 개발하는 모바일 웹 서비스입니다. 밤에 떠오른 걱정을 금고에 봉인하고, 정해진 공개 시각에 AI 요약을 확인합니다. 공개 후에는 파쇄, 10분 액션, 3분 휴식, 공감 메시지 중 원하는 도움을 선택할 수 있습니다.

이 저장소에는 BE1·BE2가 함께 개발하는 Spring 백엔드와 Python AI 서비스 계획이 있습니다.

**기술 스택** · Java 21, Spring Boot, Spring Security, PostgreSQL, Flyway, Gradle, Python(AI)
